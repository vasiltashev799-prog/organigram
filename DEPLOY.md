# Пускане в Netlify (акаунти, лични органиграми, споделяне)

Страницата е `ropes/index.html`. Сървърната част е в `netlify/` (Netlify Function `/api`,
вход с Netlify Identity, данни в Netlify Blobs). Без `/api` страницата работи като досега –
локално в браузъра, без вход.

## 1. Свържи репото
Netlify → **Add new site → Import an existing project → GitHub →** `organigram`.
Настройките се взимат от `netlify.toml` (публикува `ropes/`, функциите са в `netlify/functions`).
Build command не е нужна.

## 2. Включи Identity
Сайтът → **Identity → Enable Identity**, после **Registration preferences → Invite only**
(никой не може да си направи акаунт сам).

## 3. Задай две променливи
Сайтът → **Site configuration → Environment variables**:

| Име | Стойност |
|---|---|
| `ADMIN_EMAILS` | имейлът ти (повече имейли – със запетая) |
| `SETUP_TOKEN` | дълъг случаен низ, само за първоначалната настройка |

После пусни нов deploy (Deploys → Trigger deploy).

## 4. Първи администратор
Отвори `https://<сайтът>/#setup`, въведи имейла от `ADMIN_EMAILS`, парола и `SETUP_TOKEN`.
Работи само ако още няма нито един потребител. След това **изтрий `SETUP_TOKEN`** – така
настройката се изключва.

## 5. Колегите
Влез → **Потребители** → въведи имейл и парола (има бутон-генератор) → предай ги на колегата.
Смяна на парола и изтриване на акаунт – от същия екран. Не се изпращат имейли.

## Как се ползва
- **Органиграми** – личен списък; „Споделени с мен“ са тези, на които друг те е дал достъп.
- **Сподели** (само собственик): добавяш имейл като *Редактор* или *Само четене*, махаш достъп по всяко време.
- Запазва се автоматично. Ако двама редактират едновременно, вторият получава избор: да зареди новата версия или да презапише.
- Колегите на отворена органиграма виждат чуждите промени до ~15 секунди.

## Проба без Netlify
`npm run dev` → http://localhost:8899 (ана `ana@test.bg` е администратор; `bob@test.bg`, `eve@test.bg`; парола `parola123`).
Памет вместо Blobs – данните се губят при рестарт. `npm test` пуска проверките на правата.

## Добре е да знаеш
- Изтриването на акаунт не трие органиграмите му.
- Данните са само в Netlify Blobs: за резервно копие ползвай **Запази** (JSON) или **PDF**.
- Безплатният план на Netlify е на кредити; при изчерпване сайтът се паузира – следи използването.
